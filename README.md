# مساري — خرائط وملاحة 3D (PWA)

كل الملفات في الجذر مباشرة (بدون مجلدات) لتعمل على GitHub Pages.

## النشر
1. ارفع **محتويات** الـ ZIP إلى مستودع GitHub (الملفات نفسها).
2. Settings ← Pages ← Branch: main / root.
3. افتح الرابط عبر HTTPS من الهاتف.

## التحديث لاحقاً
غيّر قيمة `VERSION` في أول `sw.js` (مثلاً 2.0.1) ثم ارفع الملفات. عند فتح المستخدمين للتطبيق يظهر شريط «يتوفر تحديث جديد» مع زر «تحديث الآن» وزر «إلغاء»، ويمكنه التحديث لاحقاً من الإعدادات.

## ملاحظات صادقة
- **الازدحام تقديري**: لا توجد خدمة مجانية تعطي ازدحاماً مباشراً. يُحسب من الوقت (ساعات الذروة) ونوع الطريق والتقاطعات. للازدحام الحقيقي اربط TomTom Traffic أو HERE أو Mapbox Traffic (مفتاح API) داخل `traffic.js` في المصدر.
- **بلاغات الأخطار** تُحفظ على جهاز المستخدم فقط (48 ساعة). للمشاركة بين المستخدمين تحتاج خادماً (Supabase/Firebase).
- مسارات المشي والدراجة من routing.openstreetmap.de؛ الدراجة النارية تُقدَّر من مسار السيارة.
- خوادم OSRM وOverpass وPhoton وNominatim العامة للاستخدام الخفيف.
- لم يُختبر على أجهزة iOS/Android حقيقية ولا مع خوادم الخرائط الحية (بيئة التطوير معزولة)؛ جرّب بعد النشر.

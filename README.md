# مساري — خرائط وملاحة 3D (PWA) · الإصدار 3.1

كل الملفات في الجذر (بدون مجلدات) لتعمل على GitHub Pages.

## النشر
1. ارفع **محتويات** الـ ZIP إلى مستودع GitHub. 2. Settings ← Pages ← main / root. 3. افتح الرابط عبر HTTPS.

## التحديث لاحقاً
غيّر `VERSION` في أول `sw.js` ثم ارفع الملفات؛ يظهر للمستخدم «يتوفر تحديث جديد» (تحديث الآن / إلغاء) ويمكنه التحديث من الإعدادات.

## الميزات
مقدمة سينمائية · خريطة 3D (مباني، تضاريس، سماء) · موقع بدائرة صفراء وسيارة 3D أثناء القيادة · وسائل: سيارة، دراجة نارية، دراجة هوائية، مشي، **مسار مهيّأ لذوي الهمم/العربات** · مسار ملوّن بالازدحام (أخضر سلس ← أصفر ← أحمر مزدحم) · وقود وتكلفة ومسار أوفر · معاينة المسار · أفضل وقت للمغادرة · طقس الطريق · توقف ذكي بأقل انحراف · تحميل المسار للعمل دون إنترنت وتحذير الأنفاق · توجيه صوتي بالمعالم + شاشة مسارات الطريق (Lanes) · مواقف قريبة وفرصة وجود موقف · نقطة لقاء ذكية (2–4 أشخاص) · بلاغات أخطار.

## حدود يجب معرفتها (مهم قبل أي استخدام تجاري)
- **الازدحام والمواقف تقديريان**: لا توجد بيانات مجانية حية. لاستخدام تجاري اربط TomTom/HERE/Mapbox Traffic (مفاتيح مدفوعة).
- **مسار ذوي الهمم** يعتمد على وسوم OpenStreetMap (سلالم، أرصفة، مصاعد) وقد تكون ناقصة؛ لا يغني عن التحقق الميداني.
- **شاشة المسارات (Lanes)** تظهر فقط حيث تتوفر بيانات المسارات في OSM.
- **بلاغات الأخطار** تُحفظ على الجهاز فقط؛ المشاركة بين المستخدمين تحتاج خادماً.
- الخوادم العامة (OSRM وOverpass وPhoton وNominatim وOpen-Meteo) **للاستخدام الخفيف وغير مضمونة تجارياً**. لمشروع تجاري كبير: استضف الخدمات بنفسك أو اشترك بمزوّد مدفوع، والتزم بذكر © OpenStreetMap.
- لا يمكن ضمان خلو أي برنامج من الأخطاء؛ اختُبر بخوادم وهمية فقط ويلزم اختبار ميداني على أجهزة حقيقية.
